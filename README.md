# Project: Descent

## Playing

1. Download **ProjectDescentLauncher.zip** from the newest Launcher release (`launcher-v…`) on the [Releases](../../releases) page and unzip it into a folder you own.
2. Start Steam and sign in. The game only runs with Steam.
3. Run the launcher. It installs the game and keeps it up to date from the releases here.

Builds are playtest builds: please don't share screenshots or videos outside the playtest.
